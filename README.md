# Kasi_Tech Website

An HTML5-only, five-page website created from the Kasi_Tech proposal. It presents the business, promotes its technology services and gives customers ways to submit inquiries, quotation requests and booking requests.

## Pages

- `index.html` — Home page and service overview
- `about.html` — Business history, mission, vision, values and target audience
- `service.html` — Database & System analysis,IT & Network Support,Web development and design
- `inquiry.html` — Inquiry, quotation and booking request form
- `contact.html` — Contact information, hours and contact form

## How to run

1. Extract the ZIP file.
2. Open the `Part One Assignment1 WEDE5020  Somila Manentsa` folder.
3. Double-click `index.html`, or open it using a web browser.
4. Use the navigation menu to visit all five pages.

No installation, server, CSS or JavaScript is required.

## Important setup before publishing

The proposal did not include confirmed business contact details. Search all HTML files and replace:

- `+27 00 000 0000` with the correct telephone number.
- `Kasi_Tech.co.za` with the active business email address.
- `[Insert street address]`, `[Insert suburb]` and `[Insert city]` with the physical address.
- The example operating hours if the business follows a different schedule.

## Forms

The inquiry and contact forms use HTML validation and `mailto:` submission. When a visitor submits a form, the browser opens the visitor's configured email application. A hosted production website should later connect these forms to a secure server-side form handler or database.

## HTML validation

Validate every page using the official W3C Markup Validation Service: <https://validator.w3.org/>
